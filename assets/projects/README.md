# Project Assets

This directory organizes supporting media and reference material for the projects highlighted on the homepage.

Each project has its own folder with the following structure:

- `images/` – figures, charts, or screenshots that appear on the website.
- `data/` – data excerpts or supporting files used to generate figures.
- `notes/` – contextual documentation, transcripts, or citations relevant to the project.

Add or remove subfolders as needed. When you add a new project to the site, create a matching directory here so assets stay discoverable.
